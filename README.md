# Kiah Harpool

Personal portfolio for Kiah Harpool, a Chicago media leader working across media investment, strategy, systems, AI workflows, and culture.

## Site

The portfolio is an editorial home base for professional work, recognition, leadership, and personal experiments. The visual direction uses oversized typography, soft brutalist structure, and a plum, lavender, and blush palette.

## Experiments

The Work section includes Duel Cut, Encore, Duel Draw, Points, and First Light. Each project has its own case study or project page, with links to the live experiment and source repository where available.

## Stack

Astro 7, TypeScript, MDX, self hosted Fontsource typography, Satori and Sharp for Open Graph images, and GitHub Pages for hosting.

## Development

```sh
npm install
npm run dev
```

Run the full validation locally with:

```sh
npm run format:check
npm run check
npm run build
```

## Deployment

Production is built from `main`. The redesign preview is built from `soft-brutalist-editorial` and published under `/preview/soft-brutalist-editorial/` until the draft redesign pull request is approved and merged.
