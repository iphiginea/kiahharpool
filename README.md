# Kiah Harpool

Personal portfolio for Kiah Harpool, a Chicago media leader and systems thinker working across media investment, strategy, operations, AI workflows, and culture.

**Live site:** https://kiahharpool.com/

## About

This site is an editorial home base for professional work, leadership, recognition, and independent experiments. The work is connected by a recurring interest in making hidden logic visible and complicated systems easier to navigate.

The visual direction combines oversized editorial typography, soft-brutalist structure, and a plum, lavender, and blush palette.

## Selected work

The portfolio currently includes:

- **Acquired** — a museum-inspired personal object archive
- **Lakeglass** — a Lake Michigan beach-glass field guide and local specimen archive
- **First Light**
- **Duel Cut**
- **Encore**
- **Points**
- **Duel Draw**

Each project has a dedicated case-study or project page, with links to the live experiment and source repository where appropriate.

## Stack

Built with Astro 7, TypeScript, MDX, self-hosted Fontsource typography, Satori and Sharp for Open Graph images, and GitHub Pages for hosting.

## Development

```sh
npm install
npm run dev
```

Run the full validation locally with:

```sh
npm run format:check
npm run check
npm run build
```

## Deployment

Production is built and deployed exclusively from `main` to GitHub Pages at `https://kiahharpool.com/`. The site is configured for the custom-domain root (`/`) rather than a repository subpath. The former redesign branch, `soft-brutalist-editorial`, is archived and no longer participates in the GitHub Pages deployment.
